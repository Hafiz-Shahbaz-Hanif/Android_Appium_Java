# Security policy

This is a portfolio test-automation framework. It drives two freely
distributed apps — Appium's own [ApiDemos](https://github.com/appium/android-apidemos)
sample and the open-source [Wikipedia Android app](https://github.com/wikimedia/apps-android-wikipedia)
— and contains no proprietary code, production credentials, or customer data.

## Reporting a vulnerability

If you find a real security issue in this repository itself (for example, a
dependency with a known CVE, or a way this code could be misused against a
target it wasn't written for), please open a
[GitHub issue](https://github.com/Hafiz-Shahbaz-Hanif/Android_Appium_Java/issues/new)
or email **shahbazhanif87@gmail.com**. There is no bug bounty; this is a
demonstration project, but reports are still welcome and will be looked at.

Please do not open public issues about vulnerabilities in **ApiDemos** or the
**Wikipedia app** themselves — file those upstream with their own maintainers.

## Supported versions

This repository tracks `main` only; there are no maintained release branches.
